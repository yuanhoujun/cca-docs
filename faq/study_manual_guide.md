# 打谱复盘使用指南

打谱复盘可以录入对局、浏览棋谱、研究变招和添加批注。最容易混淆的是：**当前正在编辑哪一份棋谱，以及新棋谱默认保存到哪个棋库。**

> 录入另一盘棋，先点击「菜单 → 新建」。新建后可以沿用原来的棋库，但会成为一份新的棋谱。已保存的棋谱继续编辑后再保存，通常是更新原谱，不会自动新增一份。

## 一、先分清棋库、棋谱与打谱进度

| 名称 | 可以怎样理解 | 对操作的影响 |
| --- | --- | --- |
| 棋库 | 存放多份棋谱的文件夹 | 决定新棋谱保存到哪里 |
| 当前棋谱 | 此刻正在编辑的一盘棋及其变招、批注和属性 | 决定保存时新增棋谱还是更新原谱 |
| 打谱进度 | 上次编辑的内容、浏览到的局面等状态 | 开启记忆后，便于下次接着研究 |

记住棋库不代表每次保存都会新增棋谱；记住打谱进度也不代表已正式保存到棋库。

## 二、录入一盘新棋的推荐步骤

1. 如果当前棋谱还有需要保留的修改，先点击「菜单 → 保存棋谱」，确认保存成功。
2. 点击「菜单 → 新建」。棋盘回到初始局面，开始一份新的棋谱，原来的棋谱关联和属性会被清除。
3. 看一下棋盘上的棋库标签，确认是否仍要保存到这个棋库。
4. 录入着法，需要时在「菜单 → 棋谱属性」填写标题、红黑方等资料。
5. 点击「菜单 → 保存棋谱」。没有可用的私人棋库时，会要求选择棋库；已经记住有效的私人棋库时，通常直接保存到该棋库。
6. 下一盘棋重复以上步骤，尤其不要漏掉「新建」。

**例子：**第一盘保存到「周末练习」后，点击「新建」录入第二盘，再保存，两盘都在「周末练习」中。如果没有新建，而是继续修改第一盘后保存，更新的仍然是第一盘。

新建前可能出现保存提示：「保存」会先保存当前内容，成功后再新建；「不保存」会放弃当前未保存的修改再新建。提示是否出现还与设置和当前内容有关，不要依赖提示代替主动保存。如果正在自动播放，请先关闭自动播放再新建。

## 三、为什么保存时不再让我选择棋库？

为了方便连续录入，页面会保留当前棋库信息。**新建会清除当前棋谱的关联，但会保留棋库信息。**因此，只要记住的私人棋库仍然有效，新谱点击保存就可以直接放进去，无须每次重新选择。

可以通过棋盘上的棋库标签查看名称和类型。私人棋库可以作为新棋谱的直接保存目标；公共棋库标签主要表示当前浏览来源，不代表你能直接修改公共棋库。

### 想把下一盘存到另一个棋库

1. 先保存需要保留的当前棋谱，再点击「新建」。
2. 点击棋盘上棋库标签右侧的「×」，清除记住的棋库。
3. 录入新棋谱并点击保存，在选择页面选中目标棋库后确认。

选择棋库时，点击右侧的小圆圈才是选中；点击棋库名称或图标是进入子棋库。不要只进入目录却没有选中目标，详见[选择棋库](select_library.md)。

**「×」不会删除棋库或棋谱，也不会把已保存棋谱变成新谱。**如果正在编辑一份已保存的私人棋谱，即使清除了棋库标签，保存仍然会更新原谱。要调整已有棋谱的归属，请到棋库列表使用移动等管理功能；不要把清除标签当成移动或另存为。

## 四、点击保存，到底会发生什么？

| 当前情况 | 保存行为 |
| --- | --- |
| 点击「新建」后，还没有保存过 | 在目标私人棋库中新增一份棋谱 |
| 新棋谱已成功保存，继续修改 | 更新刚才保存的那份棋谱 |
| 从私人棋库打开已有棋谱并修改 | 更新原来的棋谱 |
| 从公共棋库或分享棋库打开棋谱并修改 | 保存为自己的私人棋谱副本，不直接修改来源棋谱 |
| 打开文件或 CBL 中尚未保存到私人棋库的棋谱 | 保存时新增私人棋谱，不是回写原文件 |

保存成功后，当前页面会关联到保存下来的私人棋谱。之后继续编辑、继续保存，都是更新这一份。

### 改了标题，是不是就算新棋谱？

不是。标题、比赛信息、着法和批注都是棋谱内容，修改这些信息不会解除与原谱的关联。回到第一步、退回初始局面，也只是改变当前浏览或编辑位置，不等于新建。

### 想保留原谱，再研究一个独立版本怎么办？

先保存原谱，并使用「更多 → 复制棋谱」保留完整内容，再「新建」，使用「更多 → 粘贴棋谱」载入内容，修改标题后保存。操作前确认复制成功；也可以先导出棋谱文件留存。仅研究同一盘棋的不同走法时，可以直接添加变招，无须拆成多份棋谱。

### 为什么「保存棋谱」是灰色的？

通常表示当前没有被标记为待保存的修改。仅前进、后退或浏览局面，不一定构成修改。需要保存时，检查是否已编辑棋谱内容；不要因为按钮不可点击就反复新建。

## 五、为什么重新进入页面，还是上次的棋谱？

在「设置 → 打谱复盘」中可以找到「记住上次打谱进度」。开启后，首页打谱页面可以恢复上次内容与局面；从列表打开已保存棋谱时，也可以恢复上次浏览位置。通过链接明确指定某一步时，会优先跳到链接指定的位置。

这个功能是为了接着上次学习。**返回页面、切换页面或重启应用，不应被当成新建棋谱的操作。**恢复的棋谱如果仍关联原来的私人棋谱，修改后保存仍会更新原谱。要录入另一盘棋，请明确点击「新建」。

不希望恢复上次进度，可以关闭这个选项。但关闭选项不等于立即清空当前棋盘，也不等于已经创建了新谱。

### 记住进度是不是自动保存？

进度记忆是当前设备上的恢复功能，不能代替「保存棋谱」，也不能保证未保存的修改已经同步到其他设备。完成一段录入或重要修改后，请主动保存，并确认保存成功。

如果恢复时发现原棋谱已在其他设备上发生变化，应用可能提示将本地恢复内容转为未保存副本。请先核对两份内容，再选择棋库保存，避免把副本误认为原谱已更新。

## 六、复盘时容易混淆的操作

### 前进、后退和重新走棋

前进、后退是在浏览当前棋谱。回到较早局面走出不同着法，可能形成新的变招；这仍属于同一份棋谱，保存时会一并保存。想记录另一盘独立对局，请使用「新建」。

遇到多条变招时，可以选择要看的分支。「设置 → 打谱复盘」中的遇到变招选项，会影响是直接进入第一个变招，还是弹出选择框。发现后续着法与预期不同，先检查当前分支。

### 复制棋谱与复制 FEN

「复制棋谱」用于复制整份棋谱内容；「复制 FEN」只表示当前局面，不能代替完整着法、变招和批注。需要保留整盘棋时，使用复制棋谱或棋谱文件导出。

录入另一盘棋时，建议先保存当前内容并新建，再进行粘贴或导入。不要靠粘贴内容、修改标题或回到初始局面来判断是不是已经换成一份新谱。

### 保存、导出与分享

「保存棋谱」是把内容写入棋库；「导出」是生成文件或其他形式的内容；「分享」是把棋谱提供给他人。这些用途不同。导出了文件、复制了棋谱，或仍能看到恢复的棋盘，都不能作为棋库保存成功的依据。

## 七、保存遇到问题时怎么处理？

- **提示棋库不存在：**原来记住的棋库可能已被删除。按提示重新选择有效的私人棋库，再保存当前内容。
- **提示原棋谱不存在：**原谱可能已被删除。应用会引导重新选择棋库保存为副本；此时不再是更新已删除的原谱。
- **网络异常或保存失败：**不要把当前页面上的内容当成已保存成功。先保留当前页面，恢复网络后重试；必要时复制完整棋谱或导出文件留存。
- **提示容量、订阅或棋谱过大：**按具体提示处理后再保存，相关说明见[棋谱容量说明](records_capacity.md)。
- **切换账号后重新要求选择棋库：**不同账号的棋库归属不同，请确认当前账号和目标棋库，不要假定仍能写入之前账号的棋库。

## 八、操作前快速核对

- **继续完善原来那盘棋：**直接编辑，再保存。
- **录入另一盘棋：**先保存原谱，再新建。
- **新棋谱继续放在同一个棋库：**保留棋库标签，新建后录入并保存。
- **新棋谱换一个棋库：**新建后清除棋库标签，保存时重新选择。
- **不确定会不会覆盖原谱：**先保留当前内容，明确新建后再录入或粘贴，不要仅凭标题或棋盘局面判断。
