# 导入文本棋谱使用说明

### 规范

* 回合前面有数字标识，着法之间用空格隔开

* 注解使用大括号括起来

* 不支持变招

* 起始盘面使用`FEN:`字符串表示

### 最佳实践

* 简单棋谱可以尝试通过文本棋谱的方式导入

* 如果导入失败推荐转成东萍UBB棋谱再导入

* 如果棋谱带变招，请不要使用文本棋谱的方式导入
