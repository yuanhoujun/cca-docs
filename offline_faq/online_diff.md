# 在线版与离线版有什么不同？
* 可参考以下表格，了解在线版本与离线版本的不同。

# 在线版本 VS 离线版
| 功能           | 离线版                     | 在线版                           |
|----------------|----------------------------|----------------------------------|
| 登录要求       | 不需要                     | 需要                             |
| 联网要求       | 仅部分需要                 | 需要                             |
| 棋谱容量       | 无限制                     | 最高5000                         |
| 单个棋谱大小   | 无限制                     | 最大5MB                          |
| 棋谱加载速度   | 秒开                       | 需要联网请求，较慢               |
| 批量导入       | 无限制                     | 最多一次100，且需要排队          |
| CBL棋库导入    | 可全部导入                 | 只能打开，单个导入               |
| 生成分享码     | 不支持                     | 支持                             |
| 导出全部       | 可导出为单个cab文件         | 不支持                           |
| 设备限制       | 最多绑定3台设备             | 无限制，仅与账号相关             |
| 跨平台同步     | 不支持                     | 全平台同步支持                   |
| 支持平台       | Windows、macOS、Linux      | Windows、macOS、Linux、Android、iOS |
