# 5M棋谱到底能存多少东西

以手机版本为例，1.3.0及其以前版本大约能存 **1～2万个着法节点**，1.3.1及其以后版本大约能存 **4～5万个着法节点**。

## 新旧容量对比

以下按注解较少的棋谱粗略估算：

| 对比项目            | 旧版存储格式     | 新版存储格式     |
| --------------- | ---------- | ---------- |
| 单份棋谱大小上限        | 5MB        | 5MB        |
| 可保存的着法节点        | 约1～2万个     | 约4～5万个     |
| 对应的少注解 CBR 文件大小 | 约100～200KB | 约400～500KB |

这些是帮助理解容量的预估值，不是固定的节点上限，也不是 CBR 文件的导入大小限制。局面、注解、链接以及 CBR 文件版本不同，实际结果都会变化，最终以 App 转换后的大小为准。

## 你知道一个棋谱5万个着法是什么概念吗？

按照中国象棋历史上最长的一盘对局来算，蒋川对李雪松的一盘棋达到了543步，创下了历史之最。5万的着法大约相当于92个这种超长对局。注意：这是极端情况，正常对局100回合以上已经算是很长。我们就假设是100回合，那就相当于250盘这样的长对局。

这就相当于你把几百盘的对局放到一个棋谱里面？很显然，这是非常不合理的！你真正应该要去学习的应该是如何归类整理棋谱，而不是把棋谱做成一堆臭不可闻的、无人看懂的废料！

## **如果单个棋谱可以存储5万步着法，你还觉得不够。我想，你需要的不是让象棋助手扩容，而是应该去学习如何整理归纳棋谱！**
